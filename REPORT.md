# 📄 Отчёт о разработке: Debian-пакет `bash-it-dpkg`

## 1. Цель проекта

Создать **Debian-совместимый пакет** для системной установки [Bash-it](https://github.com/Bash-it/bash-it) — популярного фреймворка для настройки Bash.

Требования:
- Установка в `/opt/bash-it`
- Поддержка многопользовательской среды
- Персональная активация через `bashitctl`
- Возможность сборки из исходников
- Простое развёртывание по прямой ссылке

## 2. Реализованные компоненты

```text

```


## 3. Ключевые особенности

| Особенность | Описание |
|------------|---------|
| **Централизованная установка** | Ядро Bash-it размещается в `/opt/bash-it` (только чтение) |
| **Персональная конфигурация** | Настройки хранятся в `~/.bash_it/enabled/` для каждого пользователя |
| **Активация через `bashitctl`** | `bashitctl activate` / `deactivate` — безопасное управление |
| **Сборка из исходников** | Поддержка `debuild`, `dpkg-buildpackage` |
| **Прямые ссылки на .deb** | Пакет доступен через GitHub Releases |


## 4. Документация и поддержка

- **README.md** — полное руководство на английском
- **man 7 bash-it-dpkg** — справка по пакету
- **GitHub Releases** — прямые ссылки на `.deb`
- **GitHub Actions** — потенциальная автоматизация (готов к внедрению)
